# steady-social

Pictures and records for the daily @steadyyy.app Instagram posts. Written by the Instagram workflow in the private Steady repo; do not edit by hand.

- `queue/` hand-made posts waiting to go out, first one goes next
- `posts/<date>-<name>/` each day's post: `post.json`, `slide-N.jpg`, `caption.txt`, and `posted.json` once it is live
